## 11.1 密钥日常管理隔离验收

在隔离数据库中使用合成账号和模拟上游，通过控制台 API 验证按名称或公开前缀搜索、状态和分组组合筛选、游标分页及改名。其他账号无法查询或修改这把密钥。已停用的密钥可以编辑，已撤销的密钥保留历史记录并拒绝编辑。

| 验收场景 | 实测结果 |
| --- | --- |
| 已消费 0.75 美元，另有 2.00 美元在途预占 | 将累计额度改为 2.749999 美元返回 409，同次提交的名称和 RPM 均保留原值。恰好 2.75 美元可保存，下一笔请求因超过额度返回 402。 |
| 清除累计额度并将 RPM 降为 1 | 同一把密钥在过去 60 秒已有两笔受理记录，下一笔返回 429。把 RPM 调至 3 后立即调用成功。 |
| 钱包和用量核对 | 三笔成功调用各预占 2.00、扣费 0.75、释放 1.25 美元。两笔被拒请求均无扣费。8.00 美元测试余额剩余 5.75 美元，在途预占归零。 |
| 密钥明文 | 仅创建响应和一次性弹窗展示完整值。关闭弹窗并刷新后，列表和编辑窗口只显示公开前缀。 |

生产构建与 73 项回归测试通过。在 390 像素宽的 Chrome 视口，使用 11 把合成密钥验证每页 10 条、末页和返回上一页。通过页面完成创建、编辑、筛选、重置和刷新，核对保存后的六位小数额度与 RPM。此阶段使用既有数据库结构。

## 10.1 首次接入验收

使用合成账号在本机 Chrome 登录，创建密钥，验证未保存时关闭弹窗会要求确认。保存后进入密钥所属分组的接入示例，刷新页面后仅能查看密钥前缀。直接运行页面生成的 Windows PowerShell 示例，使用模拟模型完成一次非流式调用。

将响应中的 OpenToken 请求 ID 粘贴到使用记录页，查询结果自动展开。该笔预占为 1.936 美元，实际扣费 0.75 美元，释放 1.186 美元。仪表盘余额减少 0.75 美元，钱包流水按相同请求 ID 匹配到一笔扣费。另一笔模拟上游返回不确定结果，页面保留预占并将扣费和释放显示为“待确认”。390 像素宽度下，调用示例和请求详情页均无整页横向溢出。生产构建与 68 项回归通过。

## 10.2 管理员后台体验验收

系统管理员可访问七个模块，运营人员可访问六个模块，审计员可访问兑换码管理及两类日志。回归测试逐页核对三种角色的入口和当前页面标记。各页继续使用原有的服务端授权检查。

生产构建和 69 项回归测试通过。本机 Chrome 使用合成账号验证了以下流程。

- 21 条兑换码按 20 条和 1 条分页。返回上一页后首条记录一致，筛选无匹配项时可重置，确认作废后显示结果。
- 用户列表支持查询、清空与重置。日志会提示无效时间区间，重置后能读取列表。
- 系统设置拒绝无效时区并显示错误。重新加载后恢复当前版本并清除错误提示。
- 在 390 像素宽度下，登录日志、操作日志及模型详情均未出现整页横向溢出。

## 10.3 模型选型与接入验收

生产构建和 71 项回归测试通过。在 390 像素宽的 Chrome 窗口中，用合成目录按名称、上游、分组和流式支持筛选。将同一模型的两个分组放在同一张表中比较，返回后保留原筛选条件。

| 单价口径（美元 / 百万 Token） | 输入 | 缓存读取 | 输出 |
| --- | ---: | ---: | ---: |
| 基础单价 | 0.30 | 0.06 | 0.90 |
| 用量分组 ×0.9 | 0.27 | 0.054 | 0.81 |
| 优先分组 ×1.25 | 0.375 | 0.075 | 1.125 |

账号起初只有优先分组密钥。选择用量分组后，页面引导创建该分组的密钥。保存后直接运行页面生成的 PowerShell 示例，模拟上游返回的请求在使用记录中已结算，实际扣费与钱包扣减均为 5 微美元。刷新和重新登录均保留模型与分组。失效组合提示返回目录，普通密钥入口仍可切换已有密钥。

## 10.4 移动端验收

在 Chrome 手机模拟视口核对已发布版本与候选版本。390 像素宽时，模型价格页的导航从 197 像素缩为 61 像素。原先 832 像素宽的费率表改为 324 像素宽的分组卡片，与可用宽度一致。后台用户列表按账号呈现状态、角色和操作。

在 320、360、390 和 430 像素宽度下核对价格与用户列表，接入入口和后台操作均可直接触达。用合成账号完成分组比价、额度兑换、密钥创建、一次模拟调用和钱包流水查账。另验证菜单键盘展开、Escape 收起并返回焦点、后台角色编辑取消，以及 1280 像素宽度的桌面导航和表格。生产构建及 71 项回归通过。
